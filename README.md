# Hooked Short Film Workflow — v2.3

Current production instructions are on the default main branch. Start with [REVIEW.md](REVIEW.md) for revision history and evidence limits. The master instructions are [SYSTEM_PROMPT.md](SYSTEM_PROMPT.md).

The goal is original narrative films strictly under 60 seconds that earn initial attention, sustain meaningful anticipation, and resolve their promise. Genre and art style remain adaptable. v2 replaces the assumption that a hook, attractive shots, and a completed export establish a compelling film.

## Development sequence

Audience and promise → competing premises → story stress tests → viewer information map → timed picture-and-sound script → visual development and performance design → opening comparison and rough playback → development review → authorized generation → actual-performance editing → separate creative/technical review → review delivery → authorized release and learning.

Default film invocation develops and presents a concrete blueprint before polished video generation. Explicit autonomous production authorization is supported, with checks and uncertainty carried forward. No automatic publication. The current brief determines whether narration is required; preserve approved voices and text.

## Use

> Read SYSTEM_PROMPT.md and its linked files from the main branch of this repository, including SMOOTH_EDITING.md. Develop a film for review: Topic [premise], audience [viewer], genre [genre], art style [medium/look], narration [required/preferred/none], final runtime strictly under 60 seconds. Compare premises, challenge obvious solutions, write the complete timed picture-and-sound script, and present the storyboard/rough-sequence findings and limitations before polished video generation. Preserve prior versions and do not publish.

After the user authorizes production, continue from the selected blueprint rather than restarting or changing approved material silently. A request to review this workflow does not authorize media generation.

The production path now includes directed narration, consistent design/acting references, phrase-to-picture timing, per-join inspection, a dedicated pacing pass, and a finished two-shot method test before bulk generation. The user's earlier Disney-quality benchmark remains an aspiration for that animated project, not a universal art style or a quality certification.

## Smoothness revision

Clean unnatural speech pauses independently, then assemble complete actions at their intended native speed. Align the important event to the words without forcing every shot boundary onto a phrase. Use motivated cuts, supported sound bridges, and purposeful breathing room. Review the connected dramatic sequence and the exact export; extra effects and a faster cut count are not evidence of better retention. This update does not revise the completed Christmas film.
