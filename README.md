# Hooked Short Film Workflow — v2 review draft

Start with [REVIEW.md](REVIEW.md) to review this proposed replacement. The master instructions are [SYSTEM_PROMPT.md](SYSTEM_PROMPT.md).

The goal is original narrative films strictly under 60 seconds that earn initial attention, sustain meaningful anticipation, and resolve their promise. Genre and art style remain adaptable. v2 replaces the assumption that a hook, attractive shots, and a completed export establish a compelling film.

## Development sequence

Audience and promise → competing premises → story stress tests → viewer information map → timed picture-and-sound script → visual/performance design → opening comparison and rough playback → development review → authorized generation → actual-performance editing → separate creative/technical review → review delivery → authorized release and learning.

Default film invocation develops and presents a concrete blueprint before polished video generation. Explicit autonomous production authorization is supported, with checks and uncertainty carried forward. No automatic publication. For the current Santa rebuild, narration is required.

## Use

> Read SYSTEM_PROMPT.md and its linked files from the v2 review branch of this repository. Develop a film for review: Topic [premise], audience [viewer], genre [genre], art style [medium/look], narration [required/preferred/none], final runtime strictly under 60 seconds. Compare premises, challenge obvious solutions, write the complete timed picture-and-sound script, and present the storyboard/rough-sequence findings and limitations before polished video generation. Preserve prior versions and do not publish.

After the user authorizes production, continue from the selected blueprint rather than restarting or changing approved material silently. A request to review this workflow does not authorize media generation.
